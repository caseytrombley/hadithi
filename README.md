# Hadithi WebApp
![Build](https://github.com/stepoutsource/hadithi/actions/workflows/deploy-main.yml/badge.svg)

Hadithi is the core Web Application of the Hadithi Platform.

## Getting Started

### Installing requirements
```
npm install
```

### Compiles and hot-reloads for development
```
npm run serve
```

### Compiles and minifies for production
```
npm run build
```
